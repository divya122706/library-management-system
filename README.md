# Library Management System

A desktop app built with Python and tkinter for managing a library's books.

## Features
- View all books in a table
- Add new books
- Issue and return books
- Books are saved in a CSV file

## How to run
1. Install Python 3
2. Open the project folder
3. Run `python code.py`
